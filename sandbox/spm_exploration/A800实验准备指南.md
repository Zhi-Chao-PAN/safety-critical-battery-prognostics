## 🔍 结果解读指南

### 成功指标
1. **收敛性**: 损失下降 ≥ 50%
2. **稳定性**: 无NaN/Inf，梯度正常
3. **物理有效性**: 物理损失占比 1-10%
4. **训练时间**: < 2小时

### 决策矩阵
| 收敛性 | 稳定性 | 物理有效性 | 推荐决策 |
|--------|--------|------------|----------|
| ≥ 50%  | ✅ 稳定 | 1-10%      | ✅ 继续SPM路线 |
| 30-50% | ⚠️ 振荡 | < 1%       | ⚠️ 需要优化 |
| < 30%  | ❌ 不稳定 | > 30%      | ❌ 切换到退路方案 |

### 退路方案准备
如果SPM验证失败，立即切换到：
1. **宏观热力学约束**: `dC/dt = -k·C·exp(-Ea/R·(1/T - 1/T_ref))`
2. **已在主分支**: `v3.5-week1` 中准备
3. **工业验证**: 该方案已在多个工业项目中验证

## 🚨 故障排除

### 常见问题
1. **CUDA内存不足**
   ```bash
   # 减小批量大小
   export BATCH_SIZE=16
   ```

2. **数据加载失败**
   ```bash
   # 使用模拟数据
   python a800_experiment.py --use-mock-data
   ```

3. **训练不收敛**
   ```bash
   # 调整学习率
   python a800_experiment.py --lr 1e-4
   ```

### 紧急熔断条件
出现以下情况立即停止实验：
1. **连续3个epoch出现NaN**
2. **损失爆炸 (> 1000)**
3. **GPU内存占用 > 90%**
4. **单次训练耗时 > 30分钟/epoch**
