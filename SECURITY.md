# Security Policy

Thanks for helping keep this repository safe to use and evaluate.

## Scope

This repository contains research and evaluation code for battery prognostics. It is not a certified safety product, and its published claims are bounded by the protocols described in:

- [README.md](README.md)
- [docs/comprehensive_experimental_results.md](docs/comprehensive_experimental_results.md)
- [docs/claim_evidence_matrix.md](docs/claim_evidence_matrix.md)

If you believe you found a security issue, unsafe default, data leak, or a claim/documentation mismatch that could cause misuse, please report it responsibly.

## Reporting

Please open a private disclosure by emailing [18652585856@163.com](mailto:18652585856@163.com) with:

- A short description of the issue
- Steps to reproduce
- Affected files or scripts
- Potential impact
- Suggested mitigation if you have one

Please avoid posting sensitive exploit details in a public GitHub issue before the report has been reviewed.

## What to Report

- Secrets accidentally committed to the repository
- Unsafe deployment defaults
- Dependency or supply-chain concerns in the published environment
- Reproducibility or documentation mismatches that materially change benchmark interpretation
- Vulnerabilities in any web, API, or deployment surface added to this repository

## Response Goal

Best effort acknowledgement within 7 days, with follow-up based on severity and reproducibility.
